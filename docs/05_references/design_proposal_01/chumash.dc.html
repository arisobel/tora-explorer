excelente - veja essa referencia visual veja abaixo um brieffing técnico Create a modern, minimal, sans-serif homepage UI for a web app called “Estrutura da Torá”, an interactive visual atlas of Jewish textual tradition. The interface should communicate semantic zoom: zoom-out reveals the big picture, zoom-in reveals deeper textual, historical and character layers. Use a clean light background, rounded cards, soft shadows, thin borders, minimal iconography and a contemporary product-design aesthetic. Avoid parchment-heavy, archaic, ornamental or fantasy-map visuals. The main center area must show three large rounded cards connected by subtle lines: 1. “Torá Escrita” / “תורה שבכתב” with chips: Chumash, Profetas, Escritos. 2. “Torá Oral” / “תורה שבעל פה” with chips: Mishná, Guemará, Tanaim, Amoraim. 3. “Halachá” / “הלכה” with chips: Rambam, Tur, Shulchan Aruch, Orach Chaim. Use color coding: Torá Escrita = blue. Torá Oral = muted green. Halachá = warm gold. Include a top navigation header with logo, product name, search bar and navigation icons. Include a breadcrumb: “Macro visão > Visão geral da Torá”. Include a zoom-depth indicator with the phrase “Cada zoom revela mais detalhe e compreensão”. Add a left vertical map-like toolbar with Navegar, Zoom +, Zoom -, Centralizar and Tela cheia. Add a small “Camadas” panel with toggles: Área da Torá, Linha do Tempo, Personagens. At the bottom, include a fixed timeline dock titled “Linha do Tempo da Torá” with eras: Adam, Noach, Avraham, Moshe/Sinai, Profetas, Tanaim, Amoraim, Gueonim, Rishonim, Acharonim. On the right, include a clean character drawer titled “Personagens”, with sections “Principais” and “Relacionados”, showing circular avatars and names such as Moshe, Rabi Akiva, Rambam, Rashi, Rabi Yochanan and Rav Ovadia. The result should feel like a premium educational knowledge atlas, modern, dynamic, highly readable and suitable for a serious Torah learning platform.
